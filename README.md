# Strikeline

A blocky multiplayer arena FPS — 40 weapons with a Gunsmith, throwables, 9 maps, bots and 7 game modes.

## Play
Download **Strikeline-Setup.exe** from the [latest release](../../releases/latest), install it, and open Strikeline.
It goes online automatically and shows your join code on the home screen — send it to a friend so they can join you.
The app updates itself from this page.

## Run from source
```
npm install
npm start        # game server on http://localhost:3080
npm run app      # desktop app
npm run dist     # build the Windows installer
npm run release  # publish an update (game files + installer) to GitHub
```
